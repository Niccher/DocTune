Semantic Sliding-Window Chunking & Overlap

How raw unstructured files are transformed into trainable instruction tokens:

  • Window Size (512–1024 tokens): Captures complete domain concepts, SOP steps, and regulatory policies within a coherent semantic boundary.
  • Sliding Overlap (64–128 tokens): Carries over trailing sentences into subsequent chunks, guaranteeing critical facts spanning paragraph boundaries are never severed.
  • Supported Formats: Deep parsing across enterprise PDFs (tables, columns), Microsoft Word (DOCX), CSV spreadsheets, Markdown, and TXT files.
Enterprise PII Redaction & Privacy Shield

Dual-engine sanitization protecting corporate confidentiality before dataset compilation:

  • Microsoft Presidio + Regex Engine: Detects and masks Social Security Numbers (SSN), credit card numbers, personal phone numbers, and enterprise email addresses.
  • Credential Scrubber: Filters out API keys, AWS credentials, JWT tokens, and private SSH keys to prevent training models on sensitive secrets.
  • PII Audit Modal: Verify all detected entities and applied redactions with one click via Ingestion PII Audit.
Embedded ChromaDB Vector Store & Hybrid RAG

In-process semantic vector indexing without external cloud containers:

  • Local Embedding Engine: Uses BAAI/bge-small-en-v1.5 running locally to generate dense 384-dimensional embeddings.
  • Persistent Vectorstore: Managed inside data/vectorstore/ with SQLite metadata and HNSW graph indexing for sub-millisecond similarity search.
  • Real-Time Attribution: Powers dynamic RAG citations in the Evaluation Playground and 4-way empirical benchmarking in Experiments.
Dataset Versioning & Cryptographic Provenance

Immutable point-in-time snapshots for reproducible ML engineering:

  • SHA-256 Manifest: Every snapshot calculates a cryptographic fingerprint of data/private_docs.jsonl stored in data/datasets/manifest.json.
  • MinIO / S3 Mirroring: Datasets are mirrored to object storage for distributed worker access and long-term archive retention.
  • Run Lineage: Every training run links back to the exact snapshot tag and hash, guaranteeing 100% audit reproducibility.
