Interpreting Real-Time Loss Trajectories

How to identify model training states from the multi-series curve:

  • Healthy Convergence: Steep logarithmic descent in steps 0–100, smoothly flattening into an asymptotic floor (typical final cross-entropy loss between 0.35 and 0.85).
  • Underfitting: Loss remains high (> 1.5) with shallow gradient changes. Indicates insufficient learning rate (e.g. < 5e-5 for LoRA), too low rank, or inadequate training epochs.
  • Overfitting / Memorization: Training loss drops near 0 (< 0.05) while evaluation perplexity deteriorates. Model memorizes tokens verbatim rather than extracting underlying domain logic.
  • Gradient Explosion / Instability: Sudden vertical loss spikes or NaN values. Remediated by lowering learning rate, activating gradient clipping (1.0), or increasing batch accumulation.
Automated Evaluation Metrics Guide

Understanding benchmark performance metrics:

  • BLEU Score (0.0 to 1.0): Measures n-gram precision overlap between the generated completion and verified ground-truth reference. Scores > 0.40 indicate strong factual phrasing.
  • ROUGE-L (0.0 to 1.0): Computes Longest Common Subsequence (LCS) recall, evaluating sentence structure retention and complete multi-token sequence fidelity.
  • Perplexity ($PPL = \exp(\text{Loss})$): Geometric mean of inverse probability per token. Measures predictive uncertainty. Lower perplexity signifies a confident, well-adapted model.
4-Way Empirical RAG Benchmark Methodology

Scientifically answers: Does fine-tuning beat retrieval on enterprise documents?

  1. Base Model (Zero-Shot): Measures foundation model knowledge without access to private document facts.
  2. Base Model + RAG: Evaluates standard RAG retrieval without model fine-tuning (high token overhead, dependent on chunk extraction).
  3. DocTune Fine-Tuned: Evaluates parametric memory alone (ultra-fast latency, zero prompt token waste, strong domain comprehension).
  4. DocTune + RAG (Hybrid): Combines internalized domain weights with real-time vector citations for maximum factual accuracy and verifiable audit provenance.
Run Provenance & Dataset Snapshot Hashing

Every experiment trial is recorded with immutable metadata:

  • Dataset Hash: SHA-256 fingerprint of data/private_docs.jsonl guarantees exact data reproducibility.
  • Hyperparameter Signature: Learning rate, LoRA rank $r$, scaling $\alpha$, batch size, and scheduler recorded in PostgreSQL.
  • Resumption Lineage: Traces whether the checkpoint originated from step 0 or was resumed from a previous run.
