From Private Documents to Production LLM in 5 Steps

DocTune Studio coordinates the complete private fine-tuning lifecycle with zero cloud leaks, automated data preparation, and full hardware governance.

1
Document Ingestion & PII Scrubbing

Upload proprietary manuals, SOPs, contracts, and datasets (PDF, DOCX, CSV, TXT, Markdown). Sliding-window token chunking preserves contextual boundaries while dual-engine PII redaction masks SSNs, credit cards, emails, and API secrets.

Presidio PII Redactor Sliding Chunks ChromaDB Store
2
Teacher LLM Synthetic Q&A & Snapshots

Harness high-capacity teacher models (local zero-cost Ollama, vLLM, or cloud models) to convert document passages into dense instruction-response pairs. Create immutable point-in-time snapshots with SHA-256 fingerprinting for reproducible training.

Universal Teacher Gateway Alpaca & ShareGPT SHA-256 Provenance
3
QLoRA / LoRA Training & FIFO Queue

Train parameter-efficient adapters using 4-bit NormalFloat (NF4) quantization or 16-bit LoRA. Automated hardware governance prevents CUDA OOMs, sequential FIFO queueing dispatches multi-job sweeps, and checkpoint resumption allows zero-loss recovery.

bitsandbytes NF4 FIFO Job Queue Checkpoint Resumption
4
Dynamic RAG Grounding & DPO Alignment

Compare zero-shot base models against fine-tuned adapters with dynamic ChromaDB vector citations. Collect operator thumbs-up and thumbs-down corrections to train aligned models via Direct Preference Optimization (DPO) using TRL DPOTrainer.

Side-by-Side Playground Dense Vector Citations DPO Preference Tuning
5
Weight Merging, GGUF Export & Hub Push

Mathematically fold adapter weights into standalone 16-bit models ($W = W_0 + \frac{\alpha}{r}BA$). Convert with 1-click into quantized GGUFs (`Q4_K_M`, `Q5_K_M`, `Q8_0`) with automated Ollama Modelfiles, or push models directly to Hugging Face Hub with generated Model Cards.

1-Click GGUF Export Ollama Modelfiles Push to HF Hub
How DocTune Studio Logic Operates

A deterministic, air-gapped data pipeline that eliminates hallucinated responses through dual-layer adaptation: parametric fine-tuning + verifiable vector grounding.

1. Ingest
PDF, DOCX, CSV parsing with sliding-window chunking.
2. Scrub PII
Presidio + regex redaction of sensitive identifiers.
3. Synthesize
Teacher LLM generates QA pairs into versioned JSONL.
4. Fine-Tune
4-bit QLoRA with VRAM limits and checkpoint resumption.
5. DPO Align
Human thumbs up/down feedback optimizes policy loss.
6. Deploy
GGUF quantization, Ollama Modelfile, or HF Hub push.
