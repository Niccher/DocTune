Enterprise Air-Gap & Data Sovereignty

How DocTune Studio guarantees complete privacy, immutable auditability, and regulatory compliance for sensitive corporate knowledge.

100% Air-Gapped

Runs offline within isolated corporate networks. Never sends weights, prompts, or documents to external cloud vendors.

Automated PII Masking

Pre-tokenization scrubber automatically removes SSNs, email addresses, phone numbers, and credentials before training.

Cryptographic Audits

Immutable SQLite & PostgreSQL audit trail tracking every operator action, setting change, training run, and model export.

Zero-Dependency RBAC

Standard library cryptographic password hashing (PBKDF2-SHA256, 100k rounds) with signed session tokens.

Cryptographic Tamper-Evident Audit Logging

Enterprise compliance requires knowing exactly who executed pipeline actions, when they occurred, and what hardware parameters were used.

Audit Log Structure:
  • • Actor Resolution: Identifies authenticated user ID, username, or operator tag.
  • • Request Context: Records client IP address, User-Agent, and unique `X-Request-ID`.
  • • Telemetry & Timing: Execution duration in milliseconds (`duration_ms`) and endpoint URI.
  • • Severity Classification: Tagged as `INFO`, `WARNING`, or `CRITICAL` for alert routing.
